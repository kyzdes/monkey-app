## 📱 Описание

Monkey Tamagotchi - это современное iOS-приложение виртуального питомца, где вы ухаживаете за милой обезьянкой. Выбирайте между Гориллой, Орангутангом, Бабуином или Гибоном, каждый со своими уникальными характеристиками, анимациями и особенностями!

## ✨ Особенности

### 🎭 Персонажи

- **Горилла** 🦍 - Сильный и спокойный
  - Высокая сила и выносливость
  - Любит бананы, листья и бамбук
  - Специальная способность: Супер сила

- **Орангутанг** 🦧 - Умный и творческий
  - Высокий интеллект и креативность
  - Любит манго, орехи и мёд
  - Специальная способность: Решение головоломок

- **Бабуин** 🐵 - Энергичный и социальный
  - Высокая ловкость и энергия
  - Любит бананы, насекомых и фрукты
  - Специальная способность: Социальная бабочка

- **Гибон** 🐒 - Акробатичный и музыкальный
  - Невероятная ловкость

  - Специальная способность: Акробатика

## 📦 Установка

### Предварительные требования

```bash

- macOS Monterey или выше
- Apple Developer Account (для запуска на устройстве)
```

### Шаги установки

1. **Клонируйте репозиторий**

```bash
git clone https://github.com/yourusername/monkey-tamagotchi.git
cd monkey-tamagotchi
```

2. **Откройте проект в Xcode**

```bash
open MonkeyTamagotchi/MonkeyTamagotchi.xcodeproj
```

3. **Настройте Bundle Identifier**

- Откройте настройки проекта
- Измените Bundle Identifier на уникальный
- Выберите вашу команду разработчика

4. **Запустите проект**

- Выберите целевое устройство или симулятор
- Нажмите ⌘R или кнопку Run

## 🏗 Архитектура

Проект следует архитектуре MVVM с использованием SwiftUI и Combine.

```
MonkeyTamagotchi/
├── App/
│   ├── MonkeyTamagotchiApp.swift    # Точка входа
│   └── ContentView.swift             # Главный контейнер
├── Models/
│   ├── Monkey.swift                  # Модель персонажа
│   ├── MonkeyType.swift              # Типы обезьян
│   ├── MonkeyStats.swift             # Характеристики
│   ├── Item.swift                    # Предметы
│   ├── Trick.swift                   # Трюки
│   ├── Achievement.swift             # Достижения
│   └── GameSettings.swift            # Настройки
├── Views/
│   ├── Main/
│   │   └── MainGameView.swift        # Главный игровой экран
│   ├── Onboarding/
│   │   └── OnboardingView.swift      # Выбор персонажа
│   ├── Shop/
│   │   └── ShopView.swift            # Магазин
│   ├── Customization/
│   │   └── CustomizationView.swift   # Кастомизация
│   ├── MiniGames/
│   │   └── MiniGamesListView.swift   # Мини-игры
│   └── Social/
│       └── SocialView.swift          # Социальное
├── Services/
│   ├── GameManager.swift             # Главный менеджер игры
│   ├── PersistenceController.swift   # CoreData
│   ├── NotificationManager.swift     # Уведомления
│   ├── HapticManager.swift           # Haptic feedback
│   └── SoundManager.swift            # Звуки
└── Utilities/
    ├── Extensions.swift              # Расширения
    ├── Constants.swift               # Константы
    └── SoundManager.swift            # Управление звуком
```

### Ключевые компоненты

**GameManager** - Центральный менеджер игрового процесса
- Управление состоянием игры
- Автосохранение
- Игровой цикл
- Обработка действий

**PersistenceController** - Управление данными
- CoreData интеграция
- Сохранение/загрузка прогресса
- Синхронизация

**NotificationManager** - Локальные уведомления
- Запросы разрешений
- Планирование уведомлений
- Игровые напоминания

**HapticManager** - Тактильная обратная связь
- Различные типы вибраций
- Игровые события

## 🎯 Игровой процесс

1. **Начало игры**
   - Выберите тип обезьяны
   - Дайте имя питомцу
   - Получите стартовые 100 монет

2. **Ежедневный уход**
   - Кормите когда голоден
   - Играйте для счастья
   - Укладывайте спать при усталости
   - Поддерживайте чистоту

3. **Развитие**
   - Зарабатывайте опыт
   - Повышайте уровень
   - Разблокируйте новые трюки
   - Развивайте характеристики

4. **Заработок монет**
   - Выполняйте ежедневные задания
   - Играйте в мини-игры
   - Получайте награды за уровни
   - Разблокируйте достижения

5. **Кастомизация**
   - Покупайте одежду в магазине
   - Экипируйте предметы
   - Меняйте жилище
   - Создавайте уникальный стиль
